# تخصصات علوم الحاسوب - موقع تعليمي

مرحبًا! هذا موقع تعليمي بسيط لطلاب علوم الحاسوب من الفصل الأول. يعرض التخصصات المختلفة ومساراتها الوظيفية والتعليمية.

## كيفية التشغيل
1. انسخ جميع الملفات إلى مجلد واحد على جهازك
2. افتح ملف `index.html` باستخدام متصفح الويب (Chrome, Firefox, Edge)
3. ستظهر الصفحة الرئيسية حيث يمكنك الاستكشاف

## كيفية التحرير
- **النصوص العربية**: تحرر في ملفات HTML (في جميع الصفحات) أو في ملف `data/jobs.json`
- **الخلفيات**: في كل صفحة تخصص، يمكنك استبدال `background` في CSS بـ:
  - صورة من Unsplash/Pexels (مثلاً: `background: url('https://example.com/image.jpg') center/cover;`)
  - أو تدرج ألوان (مثلاً: `background: linear-gradient(135deg, #1a2a6c, #b21f1f);`)
- **روابط الدورات**: في كل صفحة تخصص، ابحث عن `<!-- TODO: إضافة رابط YouTube -->` واستبدله برابط حقيقي
