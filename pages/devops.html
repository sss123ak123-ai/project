ديفوبس 🚀

ديفوبس هو الجسر بين التطوير والتشغيل. لو بتحب الأتمتة، السرعة، وحل المشاكل... يبقى ده مكانك! ⚙️🔥

💼 الوظائف المتاحة

🛠️ مهندس DevOps

يطور أنظمة الأتمتة ويُحسّن النشر والتعاون بين الفرق.

المهارات المطلوبة:

  • CI/CD (Jenkins, GitHub Actions)
  • Docker & Kubernetes
  • Linux
  • Cloud Platforms

🔍 مهندس موثوقية الموقع (SRE)

يضمن أن الأنظمة مستقرة، آمنة، وسريعة.

المهارات المطلوبة:

  • Monitoring (Prometheus, Grafana)
  • Incident Response
  • Automation
  • Capacity Planning

☁️ مهندس DevOps سحابي

يتخصص في العمل مع AWS, Azure, أو GCP لنشر وإدارة الأنظمة السحابية.

المهارات المطلوبة:

  • AWS / Azure / GCP
  • Terraform
  • Cloud Security
  • Serverless

🔒 مهندس DevSecOps

يدمج الأمن في دورة حياة التطوير من أول لحظة.

المهارات المطلوبة:

  • Security Automation
  • Vulnerability Scanning
  • Compliance
  • Secure CI/CD

📦 مهندس الحاويات

متخصص في إدارة الحاويات والتطبيقات الموزعة.

المهارات المطلوبة:

  • Docker
  • Kubernetes
  • Helm
  • Microservices
